# Phase 52 — Agrandir une case grattée

**Branche :** `{{BRANCH}}` · **Migration réservée :** aucune · **Base :** `{{PARENT}}`

## Objectif

Traiter **I-004** de `.docs/09-idees.md`. Une case révélée d'un ticket rend la planche en
`grid-cols-4` avec un `aspect-[3/5]` : sous 110 px, `.plate-optional` efface tout ce qui n'est
pas l'identité (`.docs/01-architecture.md` §4.9). Le joueur lit le nom et le score, mais jamais
le Cartel, le blason, le code de référence, ni le texte d'un panneau (Station-Service, Belvédère,
Rénovation).

Une case **révélée** devient un bouton qui ouvre une **modale** : la planche `variant="detailed"`
en grand pour une carte, le texte du panneau pour un bonus. Aucune requête : la charge utile de
révélation porte déjà tout.

## Décisions déjà prises — ne les rediscute pas

1. **La base est `{{PARENT}}`.** PR **brouillon vers `{{PARENT}}`**, jamais `main`.
2. **La modale vit dans `document.body`** via `OverlayPortal`, comme celle de la Pépite : aucun
   ancêtre transformé ne peut la décaler (§4.9, BUG-007).
3. **Seule une case `revealed` est cliquable.** `LockedCell` et `ScratchCell` ne reçoivent aucun
   `onClick` : le serveur reste seul juge de la révélation, et un tap de fin de grattage ne peut
   pas ouvrir une case qui vient d'être révélée dans le même geste si le bouton est monté **après**
   la réponse — c'est le cas, la route remplace l'élément.
4. **Deux contenus, un seul dialogue.** Carte → `Card` `variant="detailed"` (le Cartel) avec le
   blason et son attribution. Panneau → le titre du panneau et son texte, dans le même gabarit de
   dialogue (le composant de modale est partagé).
5. **Aucune requête dans la modale.** Aucune mutation, aucun `useQuery`.
6. **L'état React de la modale est une transition grossière** : il n'est pas interdit par §4.6,
   qui ne vise que le Canvas de grattage. Le sélecteur de case ouverte est un `useState`, pas un
   état par mouvement.
7. **Le bouton est accessible** : `aria-haspopup="dialog"`, un libellé français qui nomme la case
   et la carte (« Agrandir la case 7 — Lyon »), le focus rendu à la case à la fermeture.
